# Design references

73 `DESIGN.md` files pulled from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(sourced from [getdesign.md](https://getdesign.md)). Each is an AI-generated reverse-engineered
design-system analysis of a real product's marketing site -- color tokens, typography scale,
spacing, and component specs in YAML frontmatter, followed by a written design-language breakdown.

These are third-party analyses, not this project's own design system -- use them as reference
material when discussing visual direction for a page (e.g. "make this feel more like Linear's
dark minimal UI" or "Stripe's gradient-and-weight-300 look"), not as something to apply wholesale.
Finora's actual UI conventions live in `admin-portal/src/` and `frontend/src/` themselves.

One file per site, named by its `getdesign.md` slug (e.g. `stripe.md`, `linear.app.md`, `tesla.md`).
